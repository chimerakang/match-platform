# Ownership and support

- Owner: `chimerakang`
- Repository: `chimerakang/match-platform`
- Visibility: private
- Supported release line: latest minor release and the immediately previous
  minor release
- Security and compatibility defects: file a private repository issue
- Protocol changes: require an ADR, conformance fixtures, and a major-version
  compatibility decision

The owner publishes immutable SemVer tags and release artifacts. Downstream
games pin a full commit SHA; moving a pin requires their own CI and release
acceptance.
